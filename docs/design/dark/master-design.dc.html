Totals across every provider and model for the period. The whole block is one button that opens Usage by model; hover is the 04 row fill and the chevron turns 08. The chevron's 26 segment sits outside the three stats so they stay equal width.
Where the red goes, and why.
1 · The trigger caps, filled, top-left. The one thing the app does is start listening, so the brand sits on the key that starts it — and turns into red type when it is listening.
2 · The active period segment. The only choice in the usage block; filled red says which number you are reading.
3 · Toggle on-state. Binary settings read at a glance from the fill alone, with no label to parse.
4 · A 2pt bar on the selected row. Marks where Return will land, structurally, so the keycaps can stay grey and the history reads as text.
Retry and the failed row stay greyscale: hatch fill, grey label, dashed outline. Failure is a state, not a brand moment.
