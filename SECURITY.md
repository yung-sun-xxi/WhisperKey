# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in WhisperKey, please report it
privately rather than opening a public issue.

Use GitHub's private reporting: open the
[Security tab](https://github.com/yung-sun-xxi/WhisperKey/security) and click
**Report a vulnerability**. This creates a private advisory visible only to the
maintainer.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce or a proof of concept.
- The WhisperKey version affected.

You can expect an initial response within a few days.

## Supported Versions

WhisperKey is an owner-driven project. Only the latest released version
receives security fixes.
